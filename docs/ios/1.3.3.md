# 聚在工大 iOS 1.3.3

日期：2026-11-27。版本：**1.3.3 build 10**。最低 iOS 17；使用 iOS 27.2 SDK。

## 充值页自动填写手机号

点击聚焦页洗澡、洗衣余额旁的加号，或从服务页面打开官方洗衣缴费后，自动使用个人资料中已获取的手机号，填入慧新易校充值页的手机号输入框。沿用教务个人资料、慧新资料及已登录洗浴账号资料的获取顺序，不额外询问手机号。

- 官方页面和手机号分别异步加载，手机号稍晚返回时也能填写，无需重新打开网页。
- 等待官方动态表单出现；通过原生输入事件更新网页框架绑定的数据，避免只修改表面文字。
- 保留网页已填写的号码，以及使用者修改或清空的内容。
- 仅作用于官方 `121.251.19.62/charge-app/` 顶层页面中的合肥洗衣（26）、合肥洗澡（222）、宣城洗澡（223）收费项目。
- 不向其他站点、子页面框架、其他收费项目或支付确认页面填入手机号；不填写金额、验证码或密码。
- 电费按宿舍房间查询，一卡通继续打开支付宝入口；二者不套用手机号填写。
- 官方充值入口保留原地址，避免全局 WebVPN 地址转换干扰充值登录和页面识别。

未获得手机号时，官方网页仍可正常打开并使用原有手动输入流程。自动填写不触发“确认信息”、提交订单或支付操作。
