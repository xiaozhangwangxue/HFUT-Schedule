# 聚在工大 iOS 1.2.0

日期：2026-11-14。对应上游正式版 **4.21.4.1**，并包含开发分支 [`b3cb252e44f024720f6f8fb6216ad076550ee119`](https://github.com/Chiu-xaH/HFUT-Schedule/commit/b3cb252e44f024720f6f8fb6216ad076550ee119) 的更新。

本次从 2026-10-01 起核对至 2026-11-14，共 65 条提交、5 次正式发布；包含旧 iOS 1.1.0 已覆盖的 4.21.2.2 内容及后续未发布改动。完整列表见 [上游审计](upstream-audit-2026-11-14.md)。

## 教务与考试

- 兼容创新班、HTTP 200 学籍选择页面和多学籍账户，优先选择「培养类型：主修」，缺少培养类型标注时回退首个卡片。所选卡片的编号必须通过数字校验；无效时停止，不继续从其他卡片中挑选编号。
- 教务登录成功后尝试读取官方账户页的教务系统密码，并保存在本机钥匙串；网络设置增加刷新获取和官方修改密码入口。
- 保持校园网直连 / WebVPN 的会话与路由方式，避免把普通外部公告误转入 WebVPN。
- 考试除原生列表外，同步显示在**课程表与聚焦页**：课程表按考试的实际日期、起止时间和所选周次显示；聚焦显示所有未来考试以及当天尚未结束的考试。
- 考试没有 72 小时展示上限。个人截止事项的临近规则独立于考试，不能套用到考试列表。
- 成绩的「忽略平均成绩的排除计算」开关即时影响本地平均成绩与学分统计。

## 校车、日程与聚焦

- 校车新增「出行 / 所有安排」模式、日期选择、起终点筛选与方向交换；今天过滤已发车班次，先立即计算再随时间刷新。
- 保留自然星期分类；遇假期或调休提醒用户核对校方公告，不擅自替换班次类别。
- 新增本地普通日程与截止事项的添加、编辑、删除和克隆。克隆使用新记录标识，保留原日程。
- 普通日程可跨天，在课程表每天显示相应时间段；点击各天分段仍编辑同一事件。
- 聚焦页首次进入立即更新时间，前台返回时刷新；校园卡快捷按钮可设为「无 / 充值 / 付款码」。
- 生日祝福独立于远端公告；只有生日时也能显示祝福。
- 切换周次后顶部日期与课表使用一致的周次状态。

## DeepSeek 与网页摘要

- AI 助手变为原生连续对话，默认 `deepseek-flash`，可选 `deepseek-v4-pro`。
- 使用用户自己的 DeepSeek API Key，沿用网络设置中的钥匙串槽位。
- 支持停止、清空对话、错误说明与保留草稿重试。当前页面之外不保存聊天记录。
- 网页工具栏的「AI 摘要」读取当前正文，进入对话后可查看资料并发送；不会在打开网页时自动调用模型。
- 附带正文最多 24,000 字，URL 查询参数与片段会被去除；网页作为 JSON 数据提供，并明确与模型指令分开。发送时用户问题和附带正文会交给 DeepSeek 处理。

## 天气与小组件

- 实时天气卡片可打开和风天气官方详情；预警区域提供当前校区的官方预警页面。
- **默认实时天气仍由 Open-Meteo 提供**，页面明确标注来源。
- 新增 QWeather `weather/now`、`warning/now` 与 `fxLink` 解析，以及集成方显式传入自有配置的客户端。未复制或使用上游作者的天气签名凭据，普通构建不依赖新增密钥。
- 默认未接通 QWeather 预警数据流。未配置或请求失败时指引查看官方预警，只有成功的空预警响应才表示暂无预警；天气服务失败不会伪造天气或预警。
- 周课表小组件增加同步引导空态、点击打开 App 和跨日 / 短间隔刷新策略，保留共享存储写入容错。
- 公共源码和公共 IPA 中的小组件快照为空，不附带真实个人课表；安装后由使用者登录、同步。

## 备份、存储与维护

- 备份升级为 v2 JSON：包含课程、个人日程和白名单偏好，兼容旧版课程数组导入。
- 旧数组只有课程信息，不会虚构其中不存在的个人日程或偏好。
- 课程和日程原子写入；读取损坏时保留原文件并阻止自动覆盖，恢复失败或保存失败时显示错误。
- 密码、API Key、Cookie、登录身份数据不进入备份。
- 维护页面补充原生开发者环境信息；修正文档中的洗衣服务名为**海乐生活**。
- 更新文档和迁移矩阵，去掉旧的「尚无培养方案 / 校园卡原生页面」及「通过 TestFlight / App Store 分发」等不准确描述。
