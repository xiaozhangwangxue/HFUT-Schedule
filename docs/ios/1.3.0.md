# 聚在工大 iOS 1.3.0

日期：2026-11-24。版本：**1.3.0 build 7**。运行要求 iOS 17.0；发布使用 iOS 27.2 SDK。

本版按此前功能差异清单补全其中 **119 条 missing / partial 行为记录**。核对基线为 iOS 1.2.3（`5a129136`）与上游 dev `9670096e15dd04d561da08aded3828046228d6e3`，上游正式版为 4.21.4.1。197 条审计记录中还包含已有能力、上游未启用代码和平台差异，不能用 119 / 197 计算功能完成率。逐项实现、文件证据和验证范围见 [核对清单](parity-acceptance.md) 与 [机器可读记录](parity-implementation.json)。

## 课程表与聚焦

- 教务、教务 2、智慧社区、UniApp、指间工大可作为主课表来源，各自保留离线缓存；好友申请、接受与课表切换。
- 全教学周缩略图、双指缩放、周次拖动切换与回弹、空白双击新建日程、冲突课程逐项选择。
- 聚焦在当天最后一节课结束后转为明日安排，处理节假日和调休；成绩未读计数、校园网状态、实时天气与内嵌官方预警、公共日程和网课截止事项。
- 个人日程支持楼宇 / 学习平台快捷选择和 AI JSON 提示词；登录支持跳过教务及服务刷新范围说明。

## 学业与校园服务

- 自选课程计算成绩、智慧社区排名、校务行独立登录、公共考试安排、培养方案完成情况及全校方案检索。
- 选课 / 退课、已选课程、官方冲突预览；逐任务评教及批量评教，提交后读取服务器状态确认。
- 转专业批次检索、申请 / 撤销与考试面试成绩；课程、教学班、教室、挂科率的筛选与分页；证件照及班级通讯录。
- 校园卡账单搜索、范围查询、消费统计与预测；校园网登录 / 注销 / 连通检测和历史用量。
- 花洒扫码填入 MAC、格式检查、备注与启停，洗浴使用码 / 重置 / 账单 / 备用登录；第二课堂活动和图书关键词统计。
- 场地座位列表、可用时段筛选，办事大厅、就业、招生、校区新闻与教务公告 / 学院目录、提案跟踪和开发者通知。
- 可选范围的学期报告，包含课程、考试、成绩、消费、图书 / 宿舍 / 网络数据，逐卡生成 PNG 并通过系统分享。
- 云日程搜索 / 排序 / 范围筛选、下载与更新、校园邮箱注册登录、贡献和我的管理；完整第三方常用应用入口。

## 宿舍默认电费

每个校区分别保存宿舍楼、房间和电表配置；下次进入电费页及刷新聚焦时自动查询照明和空调电费。合肥使用校方实际电表编码，宣城使用对应校区电表规则。两项查询独立显示结果和错误，修改宿舍后忽略旧请求；不会将接口失败写成零余额。查询个人电费需要同时设置房间，单独楼栋不能确定个人寝室。

## 小组件、提醒与日历

- 每次成功更新课表均发布新 revision 并立即调用 WidgetCenter 重载；未收到当前版本读取回执时按 1 / 2 / 5 秒有限重试，新版本取消旧重试，回到桌面时再次请求未完成重载。
- 新增今日 / 明日聚焦小组件、小中大尺寸、字号设置及组件内刷新；周课表组件保留。
- 按实际日期和教学周规划课程 / 考试提醒，提醒可直达课程详情；前台支持课程和考试实时活动。
- 整学期实际排课日期导出，选择系统日历、更新和清除本 App 导出的事件，课程 / 考试 / 聚焦 / 云日程单项导出。
- 快捷指令、后台校园网登录、桌面快捷操作、原版深链参数、应用内启动台和真实导航返回栈。

WidgetKit 负责最终桌面刷新时间。重载调用不能替代签名共享权限，也不能保证固定秒数内更新。Live Activity 不宣称在 App 完全退出后自动开始未来课程。

## 外观、备份与网页

主题色调节、照片取色、纯黑背景、独立玻璃与模糊开关、转场和底栏样式、课表格尺寸和教师条件显示均有实际消费者。页面随当前窗口宽度布局，保留 Duo 可变窗口适配，硬件仍需验收。

备份升级到 v3，保留 v2 / 旧数组兼容，并可导入 Android ZIP / DataStore / Room 中的兼容数据。包括成绩、考试、学籍、收藏、来源缓存及可迁移偏好；恢复前预览、备份与回滚。备份可能包含个人学业信息，请自行保管；不导出密码、Cookie 或 API Key。

网页支持刷新、前进后退、页内查找、当前 / 初始链接复制分享、收藏与按域临时 Cookie；网页正文提取后可编辑再发送 AI。OCR 可下载 / 导入 / 校验 / 删除外部模型，删除后回到内置模型，保留验证码手动输入与显式登录。

## 平台和服务边界

- 上游未启用的最终场地预约、重复日程雏形等未伪造为可用功能；原版本身使用网页的业务保留官方网页。
- iOS 没有公开的系统壁纸读取接口，取色由用户选择照片；Android 磁贴、AIDL、APK 更新使用 iOS 对应机制或保留平台差异。
- 天气默认解析和风天气公开页面，失败后回退 Open-Meteo；只有确认成功的空预警才显示暂无预警。未复制上游天气签名私钥。公共页面结构变化可能影响解析，失败时仍可打开官方页。
- 云端数据上报遵循显式开关，只发匿名运行信息；不复制上游个人学号 / 姓名字段。
- `hfut-schedule://` 为有效 iOS URL scheme。扫码 / 粘贴兼容转换上游 `hfut_schedule://` 文本；下划线 scheme 不保证可由其他 iOS App 交给系统打开。
