# 聚在工大 iOS 1.3.2

日期：2026-11-27。版本：**1.3.2 build 9**。最低 iOS 17；使用 iOS 27.2 SDK。提供源码、可重新签名的 IPA 和未签名 IPA。

## 功能与修复

- 电费房间选项去掉“照明／空调”后缀，仅修改显示名。两种电表仍使用各自的实际后台编号，结果分别标明照明与空调。
- 导航目标按需创建，由 NavigationLink 和导航路径直接持有，移除依赖源按钮是否可见的临时目标登记。每个标签单独观察路径变化，底栏选择与全局校园状态分开发布，根页面初始化器不随底栏重绘反复执行；默认使用原生交互转场，避免叠加进入动画。快捷入口也使用同一条持有目标的导航路径。
- 课表不再每次进入都重新安排通知；通知与实时活动的日程展开移到后台，关闭实时活动时不展开整学期日程。日期解析使用严格且有界的缓存，避免反复创建 DateFormatter。
- 保留课表和查询中心各卡片的液态玻璃，用 GlassEffectContainer 共享背景采样。移除重复的课程长按菜单，仅保留点按查看详情；周次选择器的独立长按操作保持原行为。
- 灵动岛标题移到下方完整区域，增加圆角边缘留白，倒计时限制宽度；长标题支持两行。
- 慧新账单请求补齐 bearer 认证。兼容可空交易字段与数字字符串；消费分析逐页读取，服务器限制单页数量时不再遗漏后续账单。
- 个人信息页可直接刷新和重新登录；教务 Cookie 按实际 URL 的路径筛选。课程汇总不因教材服务暂时失败而丢失课程；选课兼容可空批次文字和字符串编号，无开放批次时明确提示。
- 邮箱加密参数中的 + 正确转义，兼容信息门户的成功状态码；可以重新获取邮箱链接。网址导航修复页面打开、收藏行按钮及分享操作，网页内部补全 JavaScript 对话框和加载错误重试。
- 挂科率添加“我的课程”点选查询，合并重复的每周上课记录；点击查询或自己的课程进入独立结果页，分页与错误状态隔离，返回查询页保留输入和课程列表。
- 呱呱洗浴金额从千分之一元换算，45080 正确显示为 45.08 元，不影响一卡通以分为单位的金额。
- 自动读取个人资料手机号并查询，优先教务个人信息，再尝试慧新和已登录的洗浴账户个人信息；不询问手机号。慧新洗衣采用收费项目 26，读取官方表单的实际账号字段。
- 聚焦直接显示洗衣、洗澡余额数字，识别“账户余额”和“现金金额（单位：元）”，不把手机号或赠送金额当余额；支持下拉强制刷新并保留可用结果。去掉这两项余额下面的来源文字。一卡通、电费、洗澡、洗衣统一使用标题右侧的纯加号充值入口；官方充值入口获取链接时只显示转圈，不再短暂闪现加载文字。
- 天气占满聚焦信息卡片底部，左右等宽分别显示“今天”和“明天”，两天之间不显示分隔线。左侧保留当前天气，右侧显示独立的明日天气预报，两侧各显示最高／最低气温；天气图标恢复 `.title2`，温度范围恢复 `.subheadline`，正文保留 `.body`，沿用原系统字体层级，窄屏时换行而不缩小字号。Open-Meteo 请求两天的每日天气代码和最高／最低温度，主天气源和免费预报并发获取。缺失、错误或日期不连续时明确显示未更新，不复用当天数据或伪造温度。聚焦不显示“暂无预警”或预警状态占位文字，有实际预警时在天气下方逐条显示，并可打开官方预警页。
- 模拟器视觉核验发现并修复浮动底栏与系统底栏重复显示；挂科率分页移到结果列表内，避免被浮动底栏遮挡。
