# 聚在工大 iOS 1.2.4

未发布草稿，已合并入 [1.3.0](1.3.0.md)。以下为 2026-11-23 的阶段记录。

原计划版本：**1.2.4 build 6**。增加宿舍默认电费查询，并加强课表更新后的小组件重载。保留 iOS 27.2 SDK、验证码自动填写与现有 Widget 共享配置。

## 宿舍默认配置与两类电费

- 保存每个校区自己的宿舍楼、房间及电表设置，切换校区时分别恢复，避免把两个校区的编码混用。
- 宣城校区选择南 / 北区后，分别查询照明与空调电表；合肥校区从校方列表分别选择照明、空调电表的楼栋和房间，使用现有同一查询接口和不同校方编码。
- 下次进入电费页自动查询已保存电表，无需每次重新选择；仍保留手动刷新和修改默认配置。
- 两项结果与失败提示分开显示；一项失败不抹掉另一项结果，也不把未配置或失败显示为零余额。
- 修改宿舍或切换校区使旧请求失效，避免旧地址的迟到结果覆盖新配置。

查询需要已登录慧新易校且校方接口可用。接口按电表 / 房间查询，因此只选择宿舍楼还不足以确定个人寝室，需同时保存房间号；不会把单间电表结果称为整栋楼总电费。

## 课表更新后重载小组件

- 新增、删除、教务同步与备份恢复成功保存后，强制发布新 revision，再立即请求重载 Widget 时间线；相同内容的显式重新同步也需要新的读取回执。
- 在尚未收到该版本的时间线读取回执时，按 1 / 2 / 5 秒间隔有限重试；新发布会取消旧版本重试，回到桌面时再请求一次未完成的重载。
- 修改学期起始配置也会重新发布，避免小组件沿用旧周次。
- 预览读取不再充当时间线回执；小组件视图按快照 revision 更新身份。设置页仍可主动强制重发。

这些操作使用 Apple 提供的 WidgetCenter 重载 API，实际桌面显示仍由 WidgetKit 调度，不能保证每台设备在固定秒数内刷新。共享组缺失、扩展被侧载工具移除或签名授权不一致时，重载请求无法代替共享数据权限；本次不将重载调用成功等同于真机已显示。

## 安装

侧载使用 `HFUTSchedule-iOS-1.2.4-resignable.ipa`，仍需自己的侧载工具重新签名并保留 Widget 扩展。另提供纯 unsigned 包和 SHA-256 校验文件。公开包内无私人课表、账号、Cookie 或描述文件。
