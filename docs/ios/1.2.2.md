# 聚在工大 iOS 1.2.2

日期：2026-11-21。版本：**1.2.2 build 4**。补齐 iOS「查询中心 → WebVPN」缺少的原版网址转换工具，包括普通链接转 WebVPN、WebVPN 链接还原和当前运行期间的全局网页转换。

## 双向网址转换

- **转换为 WebVPN 链接**：输入完整的 `http://` 或 `https://` 地址，转换主机并生成合肥工业大学 WebVPN 代理地址。手动转换不局限于 App 自动识别的校园域名。
- **WebVPN 链接还原**：输入 `https://webvpn.hfut.edu.cn/` 下有效的代理链接，还原普通网址。
- 两种模式均提供示例、输入清空、显式转换、结果复制、打开和清除结果。示例包含座位预约、图书馆及教务代理链接。
- 转换与还原都在本机离线完成，不要求先登录，也不为了转换而读取网页或发起网络请求。
- URL 的协议、显式端口、编码路径、查询参数和片段分别处理；不会在整个输入末尾强加 `/`，也不会把查询参数中的另一个网址截断。还原正确恢复端口，不把 `https-8443` 一类代理路由标记当成普通协议。
- 无效输入、非本校代理链接或损坏的加密主机得到明确错误；失败不会被显示为「已转换到 WebVPN 首页」。

## 打开结果与登录

转换成 WebVPN 结果后，已有本机保存且通过可用性检查的 WebVPN 会话时，可在 App 内打开并复用会话；否则先提示完成 WebVPN 登录。复制和离线转换不受该条件限制。

还原后的普通结果本身没有 WebVPN 登录限制。若当前启用了全局 WebVPN，点击打开时仍会按全局设置再次转换；显示和复制的还原结果仍是普通链接。

## 全局 WebVPN

开关默认关闭，状态只保留在当前 App 运行期间，不写入持久偏好。只有已保存的 WebVPN 票据通过可用性检查后才能开启；该检查不替代对校方在线会话的实际验收。

开启后，App 中普通网页的打开入口按原版语义自动转换为本校 WebVPN 链接，已经是代理地址的链接不会重复加密。CAS 登录、教务认证页面及认证回调保留原有路由，不被全局开关二次转换，以免破坏登录流程。
