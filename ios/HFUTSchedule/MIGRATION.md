# iOS 功能迁移矩阵

当前版本：**1.2.1（2026-11-14）**。本次只修复小组件同步、签名可移植性与窗口适配，上游同步基线仍为 1.2.0 的 `b3cb252e`。最终验证见 [1.2.1 更新说明](../../docs/ios/1.2.1.md#验证)。

## 1.2.1 小组件与窗口修复

| 范围 | 当前状态 | 实现与验收边界 |
| --- | --- | --- |
| 已有课表启动发布 | 已实现，待签名真机确认 | 修复 1.2.0 启动加载后未重新发布的回归；前台返回和设置页可重发。无有效本地文件时不以空数据覆盖共享快照。 |
| 重签名与共组 | 已实现，依赖实际签名 | App / Widget entitlement 使用动态 `AppIdentifierPrefix`；运行时省略 `agrp`，两目标必须保留同一首个 Keychain 组和 Widget 扩展。 |
| 空快照与学期基准 | 已实现 | 合法空快照压过旧数据，v2 payload 携带 `termStart`，兼容旧数组；公共包仍为空快照。 |
| 扩展读取确认 | 已实现，待签名真机 ACK | 写入结果和扩展读取分开。只有对应快照的扩展回执才确认已读取，App 回读或重载请求不算成功。 |
| 小组件状态与手动发送 | 已实现 | 「选项 → 偏好与配置 → 桌面小组件」提供状态与重发入口；系统实际刷新仍受 WidgetKit 调度。 |
| 签后检查 | 工具已实现 | `verify_widget_signing.sh` 检查签后包的扩展和共同组，不能对未签名 IPA 或任意侧载工具作兼容性保证。 |
| SDK 与 Duo 窗口 | iOS 27.2 SDK / 原生自适应 | 网格按当前窗口宽度与动态字体布局；编译、模拟器和真实设备的验证分别记录。 |

App Groups 与 Keychain Sharing 的使用以实际授权为准，不再沿用「免费团队一律不支持 App Groups」的绝对判断。参见 Apple [支持能力表](https://developer.apple.com/help/account/reference/supported-capabilities-ios) 与 [Keychain 配置](https://developer.apple.com/documentation/xcode/configuring-keychain-sharing)。

## 保留的未完成与平台差异

- 「默认课程表数据源」「自动刷新登录状态」等既有设置的存在，不代表智慧社区课表自动切换、冷启动后台登录等端到端流程已经验收。本次没有以这些旧设置宣布全量对齐。
- 未将上游研究中的多日期组件、`group_id` 预留、新重复日程雏形作为已发布功能。云端共建在上游暂时下线，本次不增加新的共建提交流程。
- QWeather 上游使用作者的签名配置。本项目不搬运该凭据；默认的免费实时天气和官方预警入口与上游内嵌 QWeather 数据流存在差异。未请求成功的预警数据不会显示为「无预警」。
- Android Room 迁移、系统磁贴、Husk 检测、Compose 专属外观、APK 下载与增量更新属于平台实现；iOS 使用自己的文件存储、快捷指令、SwiftUI 和签名 IPA 流程。
- 无本次真实账号网络验收或签名真机验收结果时，不将模拟器测试记作服务端或设备验收通过。部署与分发以本次实际 GitHub 发布产物为准。
